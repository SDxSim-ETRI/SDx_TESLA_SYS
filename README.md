# SDx_TESLA_SYS

Unity3D and MuJoCo-based robot simulation.

## Requirements

- Ubuntu 22.04
- Unity 2022.3.64f1
- MuJoCo 3.16.0
- Git LFS

## Installation

```bash
sudo apt install git-lfs
git lfs install

git clone https://github.com/SDxSim-ETRI/SDx_TESLA_SYS.git
cd SDx_TESLA_SYS
git lfs pull

## Run
Open SDx_TESLA_SYS_SimStudio in Unity Hub and run the scene.~
